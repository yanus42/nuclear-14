# Фактура бумаги

`PaperSurface` задаёт физический вид листа независимо от содержимого. Компонент
поддерживают окно обычной бумаги и печатные газеты. Для нового окна документа
можно использовать `PaperSurfacePanel` либо `PaperSurfaceRenderer`.
Спрайт предмета в мире этот компонент не меняет.

Пример компонента для прототипа бумажного предмета:

```yaml
- type: PaperSurface
  appearance:
    profile: N14RecycledPaper
    wear: 0.5
    fibers: 0.8
    impurities: 0.6
```

- `wear`: износ, пятна, складки и повреждение края, от 0 до 1.
- `fibers`: выраженность и количество волокон, от 0 до 1.
- `impurities`: выраженность и количество вкраплений, от 0 до 1.
- `seed`: постоянное зерно рисунка; оставить 0 для случайного назначения сервером.

Качество материала независимо от износа: при `wear: 0` волокна остаются видимыми.
Профиль `paperSurface` определяет цвет, зернистость, пятна, число и силу складок,
шероховатость края, количество и контраст волокон и вкраплений. Для гладкого
материала задайте `fiberCount: 0` и `impurityCount: 0` в профиле или обнулите
соответствующие поля `appearance`.

Фактура генерируется локально по маленькому описанию. Изображения не передаются
по сети. Волокна и пятна находятся под текстом; поверх него допускаются только
слабые складки. Размер текстур, количество элементов, фоновые задачи и кэш
ограничены. Изменение параметров качества входит в ключ кэша.
